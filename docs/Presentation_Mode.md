# Presentation Mode

Presentation Mode is the competition-facing demonstration of an experimental-preparation decision workflow. It reads only existing registered assets.

## Recommended live script

1. Ask for the ten largest Glide/Vina disagreements.
2. Ask which five should receive the next MM/GBSA budget “from here”.
3. Inspect the Plan Preview and confirm the allowlisted action.
4. Open one recommended candidate in the 3D workspace and inspect pose provenance.
5. Show Team Review Board and Activity Timeline to demonstrate researcher-in-the-loop traceability.
6. Show the computational DBTL page and explicitly state that reviewed wet-lab feedback is still zero.

## Claims allowed

- 1,633 HTVS candidates have registered same-protocol Vina evidence.
- Glide and Vina can disagree materially, motivating protocol-aware evidence acquisition.
- ATP-Navigator can turn a research intent and budget into a traceable candidate panel.
- AI recommendations, team votes and final human decisions are separated.

## Claims not allowed

- A candidate is experimentally active, safe or clinically useful.
- Computational consensus equals biological activity.
- A cached result is a calculation executed live during the presentation.
- A complete wet-lab closed loop exists.
