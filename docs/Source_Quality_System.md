# ATP-Navigator 数据来源质量体系 v1.0

**版本**：v1.0
**日期**：2026-08-24
**配套文件**：ATP_Navigator_Data_Dictionary_v1.md（字段定义）、Dataset_QC_Report.md（现状审计）

---

## 1. source_level 定义

| 等级 | 名称 | 定义 | 本项目实例 |
|------|------|------|------------|
| **A** | 原始实验论文 | 经同行评议、报告原始实验数据（含方法、菌株、数值）的论文；数据由人工从正文/图表中提取 | Steed/Wolfe 系列 5 篇（ACS Omega 2022/2025、ACS Infect Dis 2023、ACS Med Chem Lett 2024、ChemMedChem 2025）；Dupont 2017 AAC |
| **B** | 公开实验数据库 | 收录实验测量值、可追溯到原始文献的公共数据库 | ChEMBL（记录含文献 DOI）、BindingDB（记录含 monomer 链接） |
| **C** | 综述二次整理 | 综述中转引的二手数据，数值未直接核对原始论文 | Antibiotics 2023 综述（DOI 10.3390/antibiotics12040650）汇编的经典抑制剂 MIC |
| **D** | 预测数据 | 计算/AI 预测值（对接打分、MM-GBSA、模型预测活性） | 当前公开库中无此类数据；项目内部 HTVS/MM-GBSA 数据若入库须标 D |

## 2. 判定流程

```
数据来源是论文吗？
 ├─ 是：数值直接来自该论文的实验结果表/图？ → A
 │       数值是转引他人的？ → C
 └─ 否：是数据库吗？
        ├─ 记录可追溯到实验文献（ChEMBL/BindingDB） → B
        └─ 值由模型计算/预测产生 → D
```

## 3. 模型训练权重策略

| 用途 | A | B | C | D |
|------|---|---|---|---|
| **ATP 靶点微调（标签数据）** | 权重 1.0，首选 | 权重 0.8，可用（需注意数据库转录误差） | 权重 0.5，仅作补充，单独验证 | 禁止作为标签 |
| **AI 预训练（大规模弱标签）** | 1.0 | 1.0（主力来源，量大） | 0.5 | 0.2–0.3（可作预训练噪声标签或半监督信号，须与实验数据隔离评估） |
| **Benchmark 泛化验证** | 可用 | 可用（BindingDB/PDBbind 标准集） | 不可用 | 不可用（防止标签泄漏与循环论证） |
| **模型性能报告** | 仅报告在 A/B 级留出集上的指标 | 同左 | 不计入 | 不计入 |

**补充规则**：
1. 同一化合物在多个等级出现时，训练标签优先取 A；B/C 用于交叉验证该值的数量级一致性。
2. D 级数据必须与实验数据分文件/分字段存放（本项目主库中 docking_score、mmgbsa 为独立列，与 activity_value 物理隔离）。
3. C 级数据仅用于经典抑制剂的背景标注与粗略参照，不进入任何定量训练目标。
4. 任何等级升级（如 C→A）必须完成原始论文核对并记录核对人与日期。

## 4. 当前数据资产等级分布（v1 标准集，8,820 行）

| 等级 | 行数 | 占比 | 构成 |
|------|------|------|------|
| A | 323 | 3.7% | 5 篇 ATP 合酶抑制剂论文 + AAC 2017 + 综述中 3 条为 C |
| B | 8,494 | 96.3% | ChEMBL MIC 6,414 + BindingDB 结合数据 2,080 |
| C | 3 | <0.1% | 综述汇编的 DCCD/tomatidine/piceatannol MIC |
| D | 0 | 0% | 无（公开来源无计算数值） |

**结论**：当前资产以 B 级数据库数据为主体（适合预训练），A 级高质量靶点数据 323 条（适合 ATP 靶点微调的种子集）。后续扩库应优先提升 A 级占比。
