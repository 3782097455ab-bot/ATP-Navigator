没有超过v3。这里“恢复”仅指静态MM/GBSA计算标签定义的Top5，不是湿实验命中。新旧RMSE差的fold-cluster bootstrap 95%区间分别为[-0.08264,0.20156]及[-0.25783,0.31294]，均跨0；样本很小，不能宣称显著优劣。

替换实验中，新10个特征占最终全样本拟合模型gain约4.51%；这只是模型内部分裂贡献，不是因果贡献或泛化提升。详细文件：

- `results/release_v1_shadow_replace_atp_002/`：第二轮及feature_importance。
- `models/experiments/`：两轮独立模型/参数/特征；未提升为正式Model v5。

## 5. 哪些信息确实学到了，为什么没转化成内部提升

在同论文、同assay的scaffold OOF中，2025鲍曼ATP任务（10样本、3 scaffold）RF的Spearman为0.7212，pActivity RMSE 0.1944，对应训练均值基线RMSE 0.2491；2024铜绿ATP任务（19样本、14 scaffold）RF Spearman 0.5667，RMSE 0.5510，均值基线0.7224。这说明存在可学习的局部结构—端点关系，但不是独立论文验证，也不是内部候选活性已预测准确。

主要瓶颈：

- 化学空间仍远：17内部候选到旧参考的平均最大相似度0.1978，新39参考为0.2355，最高0.3014；即便去盐/中和后比较，最高也只有0.3714。
- 全库1633候选对新参考：最大相似度0.4308；≥0.4仅3个，≥0.5为0。更多同系列文献记录不会自动变成内部化学系列的近邻证据。
- 任务不同：外部学习ATP合酶实验IC50，内部考核的是MM/GBSA计算排序。更贴近MM/GBSA不自动等于更合理的实验优先级，反之亦然。
- 49条分散在6个assay；同论文、同系列聚集，不能看作49条同条件独立证据。
- 质量提升很重要，但不会自动把未知协议、未计算的MM/GBSA或内部实验结果补齐。

## 6. 论文归档与方法启发

全文位置：`data/literature/papers/atp_release_v1/`（本地，Git默认忽略）；索引`data/literature/release_v1_papers*.json`。另见阅读笔记。

从论文得到的设计启发：ATP合酶功能抑制、ETC抑制、整菌MIC和细胞毒性应成为可并列查看而不可互换的证据；侧链碱性、外膜通透与外排可能使酶学效应和整菌表现不一致。这支持实验前多证据取舍，而非将所有结果压成一个“活性”标签。此处为方法推论，不是本项目测量结果。

## 7. 下一轮优先级

1. 恢复真实计算能力：取得可执行环境/许可并确认grid及完整协议。用40预算队列作为待讨论输入，经过XP/pose和协议门控后再做同协议MM/GBSA。没有grid时可另立经研究者确认的新协议，但不得声称等价于历史协议。
2. 按本项目候选scaffold检索有结构/端点/原文定位的直接ATP数据，而非只增加泛抗菌MIC数量；优先缩小化学空间距离。
3. 从这5篇论文补充同化合物的酶学—ETC—MIC对照和制样/质子化信息，作为证据冲突提示与适用域说明，不直接改为训练标签。
4. 在预先冻结的独立集合/协议下验证候选选择价值。当前没有内部湿实验，保留回填/审查/独立版本接口即可，不补造数据。
