# 研序智航公测版用户指南

## 定位

研序智航是面向虚拟筛选后实验决策的 AI 辅助候选优先级工作台。当前科学实例来自 ATP 合酶项目；界面用于查看和整合已经登记的结构、对接、MM/GBSA、分子性质、外部知识和模型输出。它不生成实验结果，也不把计算排序解释为真实活性。

## 启动

在 Windows PowerShell 中进入仓库根目录：

```powershell
.\scripts\start_yanxu_zhihang.ps1
```

浏览器访问 `http://127.0.0.1:8501`。这是本机界面，不要求把候选或研究数据上传到第三方服务。

## 页面

1. **智能研究助手**：自然语言查询、结构化意图、计划预览、人工确认和结果回到会话的统一入口。
2. **工作台首页**：实时显示候选、生成结构、Vina证据、证据获取面板、活动任务和工具能力。
3. **候选库**：统一查询HTVS、内部候选和生成结构；身份映射不按名称或排名猜测。
4. **证据矩阵**：区分可用、缺失、未知和不适用；缺失值不按0处理。
5. **协议比较**：查看Glide/Vina/MM/GBSA的一致性与排名差异；协议一致性不等于活性。
6. **决策工作台**：读取冻结模型和版本化影子决策；切换模式不会重训模型。
7. **证据获取**：回答“预算有限时下一份高成本证据算谁”；信息价值分数仅为启发式。
8. **三维结构**：查看登记的7P3W受体、协议特异性构象和邻近残基。
9. **分子扩展、计算任务、工具能力**：查看版本化结构谱系、任务状态和真实工具可用性。
10. **实验反馈**：为未来真实实验结果保留质控、人工审查和独立版本入口。
11. **团队复核、活动记录、迭代闭环**：保存研究者意见并展示可追溯研究过程。
12. **外部基准、项目历程、演示模式、导出中心**：用于资源核查、比赛演示和带元数据导出。

## 推荐演示流程

智能研究助手（协议分歧查询 → 形成证据获取计划 → 人工确认）→ 三维结构 → 团队复核 → 活动记录 → 演示模式。

## 当前限制

- 尚无经审核的 ATP 抑制、MIC 或毒性反馈，前瞻评价为 `not_available`；
- Prime/MMGBSA 当前许可证不可用；Windows OpenMM 依赖链尚不足以产生可接受的 protein–ligand MM/GBSA 证据；
- Phase18B 不停止、重启或修改独立运行的 WSL Phase17.1；
- Research Console 是受限、可追溯的执行编排层，不是能自由生成科学数值的大模型；
- AI推荐、团队投票和最终人类决定严格分开，投票不修改模型分数。
