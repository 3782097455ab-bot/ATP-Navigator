# 实验结果回填入口（默认不上传 GitHub）

先复制 `data/templates/phase11_feedback_template.csv` 到这里，逐条填写真实结果。
原始测量文件一起放入本目录；`evidence_file` 使用项目相对路径，并填写文件 SHA256。
保留菌株、靶点、实验模式、方案ID、单位、比较符、重复编号、操作人和日期。

未知结果留空。`MIC`、`ATP_IC50`、`MMGBSA`、`CC50`分开；MMGBSA为 computational，其余为 experimental。
`<`、`>`数据保留为删失值，不能直接作为精确回归标签。

工作区可验证与导入，但不能代替人工审查。只有具名研究者审查通过才进入独立版本。
导入不自动训练，不修改历史模型，不覆盖旧数据。
目录默认被忽略，避免团队误上传未发表测量和个人信息；需要共享时应先审查并另建可发布数据包。
