# 数据目录说明

本目录同时保存历史数据资产和后续新增数据。现有文件与 `dataset_v0.2/`、`dataset_v1.0/` 保持原位，避免破坏已完成的 Phase 0–Model v2 流程。

## 新增目录

- `external/incoming/`：组员上传的原始外部表格。进入此处不代表数据已被模型采用。
- `external/curated/`：经过来源、许可、结构、单位和重复项检查后，可供后续版本引用的数据。
- `literature/`：论文和数据库出处的结构化记录，不存放未经授权的论文全文。

## 数据状态

建议使用以下状态：

- `received`：已收到，尚未审计
- `reviewing`：正在核验来源和字段
- `accepted`：审计通过，可进入后续数据集构建
- `needs_revision`：需要补字段、修单位或确认化合物身份
- `rejected`：不能可靠使用，保留原因记录

外部数据不会自动并入训练集。每次合并都应生成新数据版本，并保留来源、标签含义和审计记录。
